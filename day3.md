# Day 3 
## Careers in Cyber

### What I learned
- Cybersecurity has many different career paths
- Red Team focuses on attacking and finding weaknesses
- Blue Team focuses on defending and protecting systems
- Security analysts monitor threats and suspicious activity
- Penetration testers perform ethical hacking
- Security engineers help build secure systems

### Important Roles
- SOC Analyst
- Penetration Tester
- Security Engineer
- Digital Forensics Analyst
- Incident Responder

### Skills Needed
- Networking basics
- Linux basics
- Problem-solving
- Communication skills
- Security tools knowledge

## Notes
Today I learned about different cybersecurity careers and the responsibilities of security professionals. I also learned that cybersecurity includes both offensive and defensive roles.
