# Day 2 - Defensive Security Intro

## What I learned
- Defensive security focuses on protecting systems and data
- Blue Team helps defend against cyber attacks
- Security analysts monitor suspicious activity
- SOC (Security Operations Center) watches for threats
- Defensive security helps prevent hackers from causing damage

## Important Concepts
- Think like a Defender
- Detect Suspicious Activity
- Identify the Attack
- Stop the Attack

Today I learned about defensive security and how organizations protect their systems from cyber attacks. I also learned about Blue Team roles and monitoring threats.
